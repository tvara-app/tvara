Health check

These sites redesign without warning. The toolkit is built to degrade quietly rather than break the page — so when a selector stops matching, everything still looks fine while running on a fallback. This tells you which it is, on whichever chat tab you have open.

What this reads

It asks each open chat tab to describe itself: which platform adapter is running, how many messages it can see, whether those messages still match the platform's own attributes, and whether the composer and scroller were found. No message text is read, and the conversation id is stripped from the path before it is shown. Nothing is sent anywhere — the report is built in your browser and only leaves it if you copy and paste it.
