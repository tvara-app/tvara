Allowance accuracy

Every percentage in the popup comes from a field one of these providers actually sent your browser. This page shows you which field, so you can check it against what the site itself displays. If the two disagree, that is a bug in this extension — the number on the right is the provider's.

Checking asks each provider you are signed into for your current allowance, using the session already in your browser. Nothing is sent anywhere else, and response text is never stored — only key names and numbers, which is all the parser reads.
