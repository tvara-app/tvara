# Tvara user guide

Tvara keeps long AI chats responsive, searchable, and backed up locally. It never deletes provider messages or sends chat text, titles, prompts, or chat URLs to Tvara.

## Supported launch environment

Use current Chrome Stable or Beta on Windows, macOS, Linux, or ChromeOS, or current Edge on Windows or macOS. Mobile Chrome, Firefox, Safari, and unsupported browser versions are outside this launch.

Tvara runs on ChatGPT, Claude, Gemini, Perplexity, DeepSeek, and Grok. A provider interface change can temporarily affect that provider’s features.

## Get started

1. Install Tvara from Chrome Web Store or Microsoft Edge Add-ons.
2. Pin it from your browser’s Extensions menu if you want faster access.
3. Open a supported AI chat. Tvara adds local controls after the page loads.
4. Open the extension popup for settings, backup, account, and device controls.

## Features

### Speed engine, minimap, and outline

The speed engine reduces browser work for messages outside the visible part of a long loaded conversation. It does not remove, modify, or send messages. Use the minimap and outline to move through the conversation.

### In-chat search

Use **Alt+Shift+F** to search the conversation open in the current tab. Browser shortcut settings can change this key combination.

### Local archive search and Context Bridge (Pro)

Tvara saves chats you open on supported sites to local extension storage. Open **Total Recall** with **Ctrl+Shift+K** (or **Command+Shift+K** on macOS) to search that local archive. Use **Context Bridge** with **Ctrl+Shift+U** (or **Command+Shift+U**) to add selected archived text to the prompt you are writing.

### Export (Free) and encrypted local backup (Pro)

Exports are written to your Downloads folder without a licence. Encrypted backup files require Trial or Pro; choose and retain your backup passphrase yourself, because Tvara cannot recover it.

### Allowance display

Tvara shows a plan allowance only when it can read a figure the provider displays. “Not reported” means it has no reliable value to show.

## Trial and Pro

Free features work without an account. Select Google sign-in only when you want to start the seven-day trial, buy Pro, restore a purchase, or manage devices. Pro is a one-time $1 purchase for local archive search, encrypted backup, restore, and Context Bridge on up to five devices.

The licence service receives entitlement and device proof for these actions; it never receives chat content. A signed, unexpired local entitlement continues to work when the issuer is temporarily unavailable. New trials, purchases, restores, device changes, and sign-out wait for the issuer to recover.

## Permissions

- `storage` and `unlimitedStorage` keep your settings and archive locally.
- `downloads` writes exports and backup files you request.
- `alarms` schedules local backup and entitlement checks.
- `notifications` shows local status notices.
- `identity` starts Google sign-in only after you choose it.

Host access is limited to the supported AI sites and Tvara’s post-purchase page. Tvara does not request access to other sites, browser history, tabs, cookies, bookmarks, or web requests.
